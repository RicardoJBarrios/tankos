# @tank-os/units-json-http

JSON/HTTP persistence adapter for the independent TankOS units and conversion
catalogues. It composes `@tank-os/data-access-json-http` and uses
`@tank-os/units-zod` for transport validation. Firebase is not part of this
package.

## Running unit tests

Run `pnpm nx run units-json-http:test` for the 100% coverage-gated suite.
