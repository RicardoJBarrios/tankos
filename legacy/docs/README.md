# Legacy material

This directory documents the boundary of the retained legacy material.

- [`../veril/`](../veril/) contains the former Veril application and is not an
  Nx project.
- The former Veril product plans were consolidated and renamed as current
  TankOS product documentation before this move. They remain under
  [`.codex/product/`](../../.codex/product/) because they describe TankOS's
  active conceptual model, not an archived application implementation.

Legacy files are retained for inspection only. They are outside the Nx project
graph and the active quality and SonarCloud source scope.
