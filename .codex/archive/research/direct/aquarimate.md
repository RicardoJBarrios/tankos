# Aquarimate

**Positioning:** broad, mature aquarium log/tracker for freshwater and saltwater,
with a local device mode and an optional cross-platform cloud service.

## Observed product

Parameters, custom parameters, testing procedures and timers; recurring tasks
and activities; parameter/activity analytics; livestock and species information;
equipment, foods, supplements, dosing, notes, expenses, wish lists, photos,
timelines and backup/restore are all advertised. It supports multiple aquariums
and links to Apex controllers for parameter recording. [Official feature list](https://www.aquarimate.com/features/)

The device mode stores data locally and offers no-subscription use. Aquarimate
Live stores data in the cloud and advertises iOS, Android, Mac and Windows access
for $9.99/year; cloud storage and backup limits are separately described.
[Pricing and storage](https://www.aquarimate.com/features/)

## Model and UX pattern

The apparent model is Aquarium → parameters, tasks/activities, inhabitants,
equipment, consumables, notes, expenses, photos and timelines. The dashboard is
task-oriented; timelines connect livestock growth and care activity; charts
correlate parameters with actions. This is a feature-rich, tank-centric model,
not a neutral event or data-portability model.

## Strengths

- Breadth across logging, husbandry, livestock and analytics.
- Cross-platform continuity is a clear paid value proposition.
- Custom parameters and activity correlation address advanced keepers.

## Weaknesses and signals

Public reviews mention cloud/support reliability, crashes, inaccurate or awkward
parameter editing, incomplete species detail and subscription frustration.
[App Store reviews](https://apps.apple.com/ca/app/aquarimate/id587215055?platform=iphone&see-all=reviews)

These criticisms are anecdotal, but the same themes recur in community
comparisons: powerful breadth, steep complexity and data-entry friction.
[Reef2Reef comparison](https://www.reef2reef.com/threads/is-anyone-using-aquarimate.694271/)

## Strategic implication

Feature parity is not a credible differentiator. The stronger gap to test is
trustworthy correction/history, simpler capture and portable data without making
multi-device access feel like a lock-in tax.
