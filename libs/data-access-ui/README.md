# @tankos/data-access-ui

Angular-centric, provider-neutral CRUD presentation flow for TankOS. The
library supplies a Signal Store and a headless-friendly list component for
pagination, selection, lifecycle actions and batch confirmation hand-off.

It does not know Firestore, HTTP, Aquarium or domain-specific forms.

## Running unit tests

Run `pnpm nx run data-access-ui:test` for the 100% coverage-gated suite.
