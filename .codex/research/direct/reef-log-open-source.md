# The Reef Log and Open-Source Projects

## The Reef Log

The Reef Log presents itself as an open-source web app for parameter logging,
trends, notes, data export/import, public API access and an anonymized research
dataset. Its philosophy is data ownership and community research rather than
subscription monetization. [Official site](https://thereeflog.com/)

This is the clearest direct open-source/data-portability comparator found. Its
public claims do not establish project activity, reliability or adoption.

## Controller-oriented open source

Marine Assistant is an MIT-licensed open-source ESP32/Home Assistant project
covering temperature, levels, leaks, pH/TDS/EC/ORP, device control and local
dashboards/automations. [GitHub](https://github.com/marine-assistant/Marineassistant)

Reef-pi is another open-source Raspberry Pi reef controller, focused on hardware
control rather than a keeper's long-term domain journal.
[Project package](https://pkg.go.dev/github.com/reef-pi/reef-pi)

## Strategic implication

“Open source” splits into two opportunities: transparent data/logging and local
control. Veril should not promise both until one concrete user problem justifies
the operational cost.
