# Architecture decision records

ADRs are the canonical record for durable technical decisions. Read only the
records relevant to the current change; do not load the directory wholesale.

- `0001` — Angular, Nx and Material baseline.
- `0002` — Firebase free-first direction.
- `0003` — rendering, hosting and PWA.
- `0004` — Nx modularity and boundaries.
- `0005` — state management.
- `0006` — offline persistence.
- `0007` — testing and runtime boundaries.
- `0008` — local CodeGraph retrieval.

ADRs are not legacy merely because they record an earlier decision. If a
decision changes, mark the old ADR `Superseded`, link the replacement and keep
the historical rationale. Do not copy the same decision into multiple ADRs or
the compact contracts.
