# Candidate Feature Matrix

The sequence is a discovery hypothesis, not a release commitment. It complements
the capability map by describing release horizons; it does not define capability
boundaries.

| Horizon        | Candidate capabilities                                                                                                                            | Rationale                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| MVP foundation | Establish Aquarium, List My Aquariums, Select Aquarium and Record Observation. The first experience may begin with the real Aquarium named Veril. | Validates a private Aquarium context and the smallest durable evidence loop; multiple Aquarium roots remain valid in the domain.          |
| MVP candidates | Record Measurement, List Measurements, Configure Aquarium Location, Review Local Weather and Configure Parameter Targets are implemented.         | Extends evidence and contextual awareness with keeper-owned interpretation inputs, without biological defaults or backend infrastructure. |
| First version  | Review Recent Timeline; Review Due Care; Record Care Work; List Care Work; plan and review Care work; basic Livestock and Equipment associations. | Timeline and Care history expose accepted evidence; Due Care improves awareness without background infrastructure.                        |
| Later versions | Public presentation, reminders, Alerts, collaboration, export/import and device input.                                                            | Depends on confirmed visibility, consent, notification, portability, sharing and integration rules.                                       |
| Future         | Automation, AI assistance, advanced analytics and external integrations.                                                                          | The Vision requires proven value, safety, privacy and trusted data first.                                                                 |

Move an item only after evidence confirms both user value and the rules needed to
deliver it safely.
