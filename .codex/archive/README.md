# Archived project documentation

This archive preserves previous analysis, detailed specifications, audits,
research and the former verbose guidance. It is not part of the normal reading
path and does not authorize implementation by itself.

- `core/`: previous shared rules and guides.
- `architecture/`: detailed technical discovery and policy.
- `product/`: detailed product contracts, proposals and audits.
- `research/`: source and market research.
- `operations/`: operational procedures.
- `specifications/`: detailed historical use-case specifications.

The active entry points are the compact documents in the parent `.codex/`
directory and the ADRs in [`../adr/`](../adr/).
