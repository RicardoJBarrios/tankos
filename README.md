# Veril

Aplicación web Angular gestionada con Nx.

## Desarrollo

Instala las dependencias y arranca la aplicación:

```bash
pnpm install
pnpm nx serve veril
```

La aplicación estará disponible en `http://localhost:4200`.

## Comandos útiles

```bash
pnpm nx build veril
pnpm nx test veril
pnpm nx lint veril
pnpm nx graph
```

El código de la aplicación está en `apps/veril`.
